# Cumulus Brand Assets

This folder contains public-safe Cumulus brand exports served by the
Next.js app.

- `logo-*.svg` contains the SVG logo lockups.
- `generated/cumulus-*.png` contains small PNG exports for docs,
  previews, and downstream integrations.
- `cumulus-brand-document.pdf` and `cumulus-brand-film.mp4` are the
  public v1.0 visual identity references.

Keep raw design source files, private drafts, and oversized local export
batches out of this folder. Commit only curated runtime or documentation
assets that are safe for an open source repo.
